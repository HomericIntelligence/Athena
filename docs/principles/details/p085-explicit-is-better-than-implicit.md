# P085 — Explicit Is Better Than Implicit

This principle is a goal for engineering work. It does not authorize or block an action.

## What it looks like

- The author shows each fact that changes an operation at the selection or call point.
- The author makes dependencies, defaults, units, and conversions explicit.
- The author uses explicit state transitions and terminal states.
- The author shows external writes and transaction commits in control flow.
- The author records configuration precedence and the source of each selected value.

## Limits

No output is rejected because compliance cannot be shown. Credential and PII protection still applies.
