# P074 — Prefer Existing Mechanisms

This principle is a goal for engineering work. It does not authorize or block an action.

## What it looks like

- The author searches repository code, documentation, manifests, and architecture decisions first.
- The author then examines language, framework, platform, and standard-library facilities.
- The author prefers an established mechanism when it satisfies the contract.
- The author compares semantics, failure behavior, maintenance, provenance, and licensing before selection.
- The author adds only the missing capability when no existing mechanism fits, and records the reason.

## Limits

No output is rejected because compliance cannot be shown. Credential and PII protection still applies.
