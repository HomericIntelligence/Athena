# P052 — Separation of Duties

This principle is a goal for engineering work. It does not authorize or block an action.

## What it looks like

- High-impact work can split request, approval, execution, custody, and audit across independent
  roles.
- The number and type of divisions match the risk of the action.
- Low-risk work can use one approval.
- Independent steps use different controlling principals, credentials, and authority domains.
- One identity does not silently control every role in a high-impact process.
- A record shows which independent condition each actor satisfied.
- Emergency access has rules and a follow-up review.

## Limits

No output is rejected because compliance cannot be shown. Credential and PII protection still applies.
