# P090 — Prefer Negative Code

This principle is a goal for engineering work. It does not authorize or block an action.

## What it looks like

- The author compares two designs with equal behavior and prefers the smaller maintenance surface.
- The author removes obsolete branches, intermediaries, state, and configuration.
- The author derives data from one source instead of keeping independently changeable copies.
- The author replaces stable duplicate behavior with one implementation.
- The author counts concepts and duties, not raw lines.

## Limits

No output is rejected because compliance cannot be shown. Credential and PII protection still applies.
