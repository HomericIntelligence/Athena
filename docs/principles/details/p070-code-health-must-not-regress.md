# P070 — Code Health Must Not Regress

This principle is a goal for engineering work. It does not authorize or block an action.

## What it looks like

- The change keeps names, tests, and structure clear for the next reader.
- The change stays small and coherent, so review and revert stay easy.
- The author examines maintenance, complexity, test, operation, and security costs in context.
- The author improves one detail in the changed area when this is safe and in scope.
- When a compromise is necessary, the author records the reason, the owner, the risk, and the repair trigger.

## Limits

No output is rejected because compliance cannot be shown. Credential and PII protection still applies.
