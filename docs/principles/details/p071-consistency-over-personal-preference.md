# P071 — Consistency Over Personal Preference

This principle is a goal for engineering work. It does not authorize or block an action.

## What it looks like

- The author reads local instructions, code in the same area, public contracts, and active decisions first.
- When more than one correct alternative exists, the author prefers the established repository convention.
- The author keeps established terminology, layout, error conventions, and test style in the area.
- The author proposes clear convention changes openly, instead of diverging in one change.
- Correctness, security, and specified requirements take priority over consistency.

## Limits

No output is rejected because compliance cannot be shown. Credential and PII protection still applies.
