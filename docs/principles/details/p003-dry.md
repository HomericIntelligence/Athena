# P003 — DRY

This principle is a goal for engineering work. It does not authorize or block an action.

## What it looks like

- Each rule, schema, or calculation has one authoritative home.
- Other representations derive from that home or link to it.
- Manual copies of the same knowledge are avoided.
- Text that looks the same but means different things stays separate.
- When two representations must change together, one of them is the source of truth.
- Some duplication can keep domains isolated or aid local reading.
- An abstraction made too early can cost more than a small duplicate.

## Limits

No result is rejected because compliance cannot be shown.
