# P001 — KISS

This principle is a goal for engineering work. It does not authorize or block an action.

## What it looks like

- The design uses the minimum complexity that does the job.
- Indirection, abstraction, configuration, and process earn their place.
- The shortest path from input to outcome is a good starting point.
- Code uses current language and repository mechanisms.
- Extra layers that only move data or policy get a second look.
- A simple design is not a short design that hides state or removes validation.
- Needed compatibility, security, and reliability come before simplicity.

## Limits

No result is rejected because compliance cannot be shown.
